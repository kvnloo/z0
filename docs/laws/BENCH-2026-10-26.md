# Onboard laws baseline — 2026-10-26

## Method

Linux x86_64, Bend 2.0.34 and Lean 4.34.0. Run with `TMPDIR=$HOME/tmp/lawsbench scripts/laws-bench --output "$TMPDIR/results.json"`. Toolchains were installed via the original bootstrap into `$XDG_CACHE_HOME/z0/toolchains/<sha256(toolchain.json)>` (default cache: `$HOME/.cache`). Network downloads succeeded. No toolchain was installed under `/tmp`.

The first run began with no toolchain cache. Its wrappers captured `lean` but missed `leanc`, so that run cannot establish the full compile/verdict split. It is retained below, including its failed warm mutation phase. The corrected run wraps both `lean` and `leanc`, uses a fresh isolated HOME for each cold/warm run, and reuses downloaded archives. “Cold” means a cold checker, not cleared OS page caches. The original verifier also discards the checker for the warm run. Bootstrap always re-extracts archives in this baseline.

Peak bytes are sampled logical regular-file bytes under the run-specific TMPDIR, every 20 ms plus completion. They are a sampled high-water mark, not cumulative bytes written, allocated disk blocks, or a guarantee that a shorter-lived peak was seen. Compiler time is the sum of sequential `lean`/`leanc` subprocess wall times; verdict time is total invocation wall time minus those subprocesses. Peak for checker and verdict is shared because both are one Bend invocation. Parity and mutation include their original verifier re-entry costs.

## Decision

Build the checker cache: the corrected measurements show a material compile share. The initial genuinely uncached download/extract/bootstrap took 70.36786341801053 s. The initial warm mutation reference failed with `the kernel did not build (lean: )`; this is a failed measurement, not a killed mutant. The corrected full cold and warm suites passed without weakening any test. The cause of that transient compiler failure is not established.

No evidence supports the historical 560-second figure. These are local measurements only; macOS and CI timing remain outside WP1–3.
