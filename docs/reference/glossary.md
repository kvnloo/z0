# Glossary

| Term | Meaning |
|------|---------|
| **Owned component** | A surface with a Zer0-owned semantic responsibility. Installable. |
| **Upstream system** | An external system Zer0 depends on or executes through. Never installable. |
| **Delegated source** | An authority Zer0 *discovers* facts from and never recopies. |
| **Contract** | A generic cross-system interface. |
| **Adapter** | An implementation-specific wire surface, named to its harness. |
| **Plane** | A responsibility grouping (cognition, context, measurement, …). |
| **Harness** | The thing that actually runs a turn. Hermes, DeepSeek Harness, OMP are peers. |
| **architecture_status** | Where the design lives: merged / open_pr / branch_only / local_only / planned / legacy / superseded. |
| **implementation_status** | Whether it runs: live / canary / experimental / pre_activation / idea. |
| **tested_ref** | The ref last validated for install — independent of both statuses above. |
| **upstream_head** | A **live** fact, discovered by `z0 registry doctor`. Never committed. |
| **Receipt** | Structured audit record (decision, cognition, or usage). |
| **Verified success** | Outcome confirmed by a verifier, not by model prose. |
| **Qualify** | Evolution Lab confirms a candidate cleared the frozen gates. |
| **Publish** | z0evals freezes the reproducible study. |
| **Activate** | z0intelligence moves a qualified policy shadow → canary → active. |
