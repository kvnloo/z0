# Glossary

| Term | Meaning |
|------|---------|
| **Component** | Independently installable repo with a registry entry |
| **Profile** | Named set of components for `z0 init` |
| **Interface** | Versioned contract between components |
| **Receipt** | Structured audit record (e.g. decision receipt) |
| **Verified success** | Outcome confirmed by a verifier, not model prose |
| **Frontier** | Paid / cloud model usage in Tokenomics reports |
