# What is Zer0?

Zer0 is personal AI infrastructure organized as **independently useful components** with shared measurement and contracts.

- **OMP** runs the coding agent (CLI, voice, desktop stage).
- **Tokenomics** measures token and cost economics with reconciliation.
- **z0intelligence** learns personal policy over time.
- **Flow** predicts desktop context and prepares next actions.
- **Kerdoios** routes work across frontier and local models.

`kvnloo/z0` is the map — not another agent runtime.
