# Choose a profile

| Profile | When |
|---------|------|
| `minimal` | Agent only, no measurement yet |
| `core` | Default — agent + Tokenomics |
| `personal` | Add z0intelligence for learned policy |
| `desktop` | Add Flow for predictive desktop |
| `compute` | Add Kerdoios for routing |
| `research` | z0int + Evolution Lab + frontier-kb |
| `full` | Everything stable/canary |

```bash
./z0 init --profile desktop
./z0 add kerdoios   # à la carte
```
